# Dr. Bemnet Wondimagegnehu Mersha — Academic & Research Portfolio

Personal academic and research portfolio website for **Dr. Bemnet Wondimagegnehu Mersha**, Postdoctoral Researcher in Control Science & Artificial Intelligence at the School of Automation, Beijing Institute of Technology (BIT).

Central Brand Concept: **"Engineering Trustworthy Intelligence"**

---

## 🎨 Design System & Visual Identity

- **Aesthetic**: Swiss Editorial Minimalism / Quiet Academic Luxury
- **Canvas Background**: Pure White (`#FFFFFF`)
- **Primary Authority & Headings**: Oxford Academic Navy (`#1B365D`) — Bold display typography (`Source Serif 4`)
- **Subtitles & Metadata**: Cool Scholarly Slate (`#5A6B7C`) — Slick italic typography
- **Body Text**: Deep Charcoal Slate (`#2C3E50`) — Highly legible technical sans-serif (`Inter`)
- **Narrative Voice**: 100% first-person scholarly narrative

---

## 🛠 Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Typography**: [Google Fonts](https://fonts.google.com/) (`Source Serif 4` & `Inter`)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript 5](https://www.typescriptlang.org/)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

### 4. Run Production Build
```bash
npm run start
```

## 🌿 Git Workflow & Continuous Integration

This project follows standard git flow practices:

- **Branching Model**:
  - `main`: Production-ready code.
  - Feature branches: `feature/<feature-name>` for incremental changes.
- **Continuous Integration**:
  - Automated GitHub Actions workflow located at [`.github/workflows/ci.yml`](.github/workflows/ci.yml).
  - Validates ESLint rules and builds the production bundle on every push and pull request to `main`.
